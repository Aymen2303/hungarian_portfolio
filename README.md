# Flutter Developer Portfolio

A responsive portfolio built with HTML, CSS, and vanilla JavaScript, intended for deployment to GitHub Pages through GitHub Actions.

## Before publishing

1. Add your final résumé PDF as `resume/Aimen_Lalaibia_CV.pdf`.
2. Replace the generic GitHub and LinkedIn URLs in `index.html` with your real profile URLs.
3. Review all project descriptions and confirm each detail is safe and accurate to publish.
4. Add approved DaryService screenshots to `assets/images/` and update the case study. Current artwork is illustrative and is not a screenshot of the product.
5. Review the home-services project disclosure and update it only with confirmed details.
6. Check that the résumé contains only contact information you want public.

## Deploy

1. Create a GitHub repository for the portfolio and push these files to the `main` branch.
2. Open repository **Settings → Pages**.
3. Set the build and deployment source to **GitHub Actions**.
4. Push to `main` or manually run the **Deploy portfolio to GitHub Pages** workflow.
5. Open the URL shown in the workflow's deployment environment.

## Privacy

This portfolio is designed to describe private work without publishing its source code. Do not add private repository links, credentials, API keys, customer data, internal URLs, or unapproved screenshots to a public repository. A private source repository does not make this portfolio repository private.
